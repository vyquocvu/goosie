## Architecture Issues

### [P1] CanvasRenderer nil window panic
**File:** `internal/renderer/canvas.go:79-93`
**What:** `onImageLoaded` calls `cr.window.Canvas().Refresh(...)` without a nil check on `cr.window`. If an image loads before `SetWindow` is called, this panics.
**Fix:** Add defensive nil check inside the `fyne.Do` callback so the refresh is a no-op when window is nil.
**Effort:** S (15 min human)
**Priority:** P1
**Status:** done (2026-04-14) — moved nil guard inside fyne.Do callback

### [P1] CSS external load race condition
**File:** `internal/renderer/renderer.go:247-268, 424-463`
**What:** `loadExternalCSS` runs in a goroutine and appends to `r.stylesheet.Rules` inside `fyne.Do`. `Refresh()` reads `r.stylesheet` without any mutex. Concurrent modification = data race.
**Fix:** Add `sync.RWMutex` to `Renderer` protecting `stylesheet` — read lock in `Refresh()` and `ComputeLayout`, write lock in `loadExternalCSS`'s fyne.Do callback.
**Effort:** S (30 min human)
**Priority:** P1
**Status:** done (2026-04-14) — added stylesheetMu sync.RWMutex, read lock in Refresh(), write lock in loadExternalCSS and RenderHTML

### [P2] Distribution pipeline missing
**What:** No automated multi-platform release pipeline. Users can `go build ./cmd/browser` but there's no CI/CD for GitHub Releases or cross-platform binaries (linux/darwin/windows, amd64/arm64).
**Fix:** Add GitHub Actions workflow that builds and attaches binaries to GitHub Releases on tag push.
**Effort:** S (2 hr human)
**Priority:** P2
**Status:** done (2026-06-20) — implemented in Goosie Browser Foundation milestone

## Security Issues

### [P2] No TLS certificate verification configuration
**File:** `internal/net/fetcher.go:22-33`
**What:** `Fetcher` uses `&http.Client{Jar: jar}` with no custom transport. Basic HTTPS is supported via `http.DefaultTransport` but there's no way to configure client certificates, certificate pinning, or inspect the certificate chain.
**Fix:** Add `tls.Config` support to `Fetcher` for advanced TLS use cases. For basic HTTPS the default transport is sufficient.
**Effort:** M (1 hr human)
**Priority:** P2
**Status:** done
