# HTML Element Conformance Tracker

Generated by `make html-audit` from `internal/conformance`. Source of truth for element coverage: the [MDN HTML elements reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements).

**Score (audited standard elements): 111/132 supported (84%), 21 partial, 0 missing.**

## Workflow (fix one element at a time)

1. Pick the next `partial`/`missing` element below (work category by category).
2. Reproduce: `go test ./test/internal/conformance -run TestElementAudit -v` and the fixture in `internal/conformance/registry.go`.
3. Fix the renderer (UA default in `internal/renderer/default_style.go`, block classification in `node.go`, layout/paint special-casing).
4. Verify vs Chromium: `go test -tags=e2e ./test/e2e -run TestHTMLConformance` (computed-style + geometry comparison, ratcheted score).
5. Regenerate this tracker: `make html-audit`. Commit renderer fix + tracker delta together.

Status meanings: `supported` = parsed, correct default display class, text visibility as browsers. `partial` = rendered with divergent defaults or semantics. `missing` = dropped from the render tree.
